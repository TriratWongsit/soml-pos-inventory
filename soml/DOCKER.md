# รันอำพร OMS ด้วย Docker

ทางเลือกเพิ่มจากชุดติดตั้ง `install.bat` และ `start.bat` ตามคำแนะนำของกรรมการสอบ (K-8) Docker เปิดทั้งสี่หน่วยในคำสั่งเดียว คือ ฐานข้อมูล MySQL ระบบหลังบ้าน บริการพิมพ์ และหน้าเว็บ ไม่ต้องลง Node.js หรือ MySQL ในเครื่อง

## ต้องมี

- Docker Desktop (Windows หรือ Mac) หรือ Docker Engine กับ Docker Compose (`docker compose version` ต้องตอบเลขรุ่น)

## เปิดระบบ

ในโฟลเดอร์ `soml`

```
docker compose up -d --build
```

ครั้งแรกใช้เวลาหลายนาที เพราะต้องดาวน์โหลดและ build เสร็จแล้วเปิด `http://localhost:8080` มือถือในวง Wi-Fi เดียวกันใช้ `http://<IP เครื่อง>:8080`

ครั้งแรกระบบสร้างฐานข้อมูล ใส่สินค้า 783 รายการ และสร้างบัญชีตั้งต้น 4 บัญชีให้เอง ดูชื่อบัญชีใน `db/seed/seed-users.js`

## ปิด เปิด ดูสถานะ

| ต้องการ | คำสั่ง |
|---|---|
| ดูว่าทุกส่วนทำงานไหม | `docker compose ps` |
| ดูข้อความของระบบหลังบ้าน | `docker compose logs -f backend` |
| ปิดระบบ (ข้อมูลยังอยู่) | `docker compose down` |
| อัปเดตเป็นโค้ดรุ่นใหม่ | `docker compose up -d --build` |
| **ลบข้อมูลทั้งหมด** เริ่มใหม่ | `docker compose down -v` |

ข้อมูลร้านเก็บใน volume ชื่อ `db-data` ปิดเครื่องหรือ `docker compose down` แล้วไม่หาย ห้ามใช้ `-v` ถ้าไม่ได้ตั้งใจลบข้อมูล เมื่ออัปเดตโค้ด ระบบหลังบ้านปรับโครงสร้างฐานข้อมูลเอง (`backend/config/migrate.js`) ข้อมูลเดิมไม่หาย

## ค่าที่ตั้งได้

ใส่ในไฟล์ `.env` ข้าง `docker-compose.yml` ถ้าไม่ใส่จะใช้ค่าเริ่มต้นในวงเล็บ

| ค่า | ใช้ทำอะไร |
|---|---|
| `PROMPTPAY_ID` | เบอร์พร้อมเพย์ของร้าน 10 หลัก หรือเลข 13 หลัก **ต้องตั้งก่อนใช้จริง** |
| `JWT_SECRET` | ค่าสุ่มสำหรับลงชื่อโทเคน **ต้องตั้งก่อนใช้จริง** |
| `SEED_PASSWORD` | รหัสผ่านเริ่มต้นของบัญชีตั้งต้น |
| `AMPORN_DB_PASSWORD` | รหัสผ่าน root ของ MySQL ในคอนเทนเนอร์ (amporn-docker) ตั้งก่อนเปิดครั้งแรกเท่านั้น |
| `AMPORN_WEB_PORT` | พอร์ตหน้าเว็บ (8080) |
| `AMPORN_PRINTER_INTERFACE` | เครื่องพิมพ์ (`file:///app/printer-output` = จำลอง เขียนไฟล์ลงโฟลเดอร์ `printer-output`) |

## ข้อจำกัดเรื่องเครื่องพิมพ์

คอนเทนเนอร์มองไม่เห็นเครื่องพิมพ์ USB และคิวพิมพ์ของ Windows จึงพิมพ์ได้สองแบบ

1. เครื่องพิมพ์ที่ต่อสาย LAN: ตั้ง `AMPORN_PRINTER_INTERFACE=tcp://IP-ของเครื่องพิมพ์:9100`
2. เครื่องพิมพ์ USB อย่าง TM-T82 ของร้าน: ใช้ชุดติดตั้ง `start.bat` เหมือนเดิม ซึ่งรันบริการพิมพ์บนเครื่องที่ต่อเครื่องพิมพ์โดยตรง

## ไฟล์ที่เกี่ยวข้อง

- `docker-compose.yml` ประกาศสี่บริการ db, backend, print, web
- `Dockerfile` สร้างอิมเมจ (target `app` สำหรับหลังบ้านและบริการพิมพ์ · target `web` หน้าเว็บบน nginx)
- `docker/nginx.conf` เสิร์ฟหน้าเว็บ และส่งต่อ `/api` `/ws` ไประบบหลังบ้าน
- `docker/start-backend.js` รอฐานข้อมูล สร้างบัญชีตั้งต้นครั้งแรก แล้วเปิดระบบหลังบ้าน

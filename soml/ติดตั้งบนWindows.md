# ติดตั้งอำพร OMS บนเครื่อง PC ของร้าน

คู่มือนี้ใช้กับ PC Windows 10/11 เครื่องที่ต่อเครื่องพิมพ์ใบเสร็จ Epson TM-T82 ผ่าน USB ทำตามลำดับทีละข้อ ทุกข้อมีบรรทัด "ตรวจ" บอกว่าผ่านแล้วหรือยัง ถ้ายังไม่ผ่าน ให้ดูข้อ 5 ก่อนทำข้อถัดไป

ถ้า Claude บนเครื่องนี้กำลังอ่านอยู่: ทำตามลำดับ อย่าข้ามข้อ และอย่ากรอกรหัสผ่านแทนผู้ใช้ ให้ผู้ใช้พิมพ์เอง

## 1. ติดตั้งระบบ

ชุดติดตั้งมี Node.js และ MySQL มาในตัวแล้ว ไม่ต้องลงโปรแกรมอื่น ไม่ต้องต่ออินเทอร์เน็ต และไม่ต้องใช้สิทธิ์ผู้ดูแลเครื่อง

ถ้าเครื่องนี้เคยติดตั้งรุ่นเก่าที่ขึ้นชื่อ SOML ไว้ ให้ปิดหน้าต่างของรุ่นเก่าก่อน ไม่ต้องถอนการติดตั้ง รุ่นนี้ใช้ฐานข้อมูลของตัวเองแยกจาก MySQL ที่ลงไว้เดิม

1. คลิกขวาไฟล์ `AmpornOMS.zip` › Extract All › ช่องปลายทางพิมพ์ `C:\` › Extract จะได้โฟลเดอร์ `C:\AmpornOMS` ไฟล์ใหญ่ รอแตกไฟล์สักครู่
2. เข้าโฟลเดอร์ `C:\AmpornOMS` แล้วดับเบิลคลิก **`install.bat`** ถ้าขึ้นกรอบสีน้ำเงิน "Windows protected your PC" ให้กด More info › Run anyway
3. หน้าต่างจะถามค่า 3 อย่างเป็นภาษาอังกฤษ (หน้าต่างสีดำของ Windows แสดงภาษาไทยไม่ได้) พิมพ์แล้วกด Enter ทีละช่อง

| บนหน้าจอขึ้นว่า | หมายถึง | ใส่อะไร |
|---|---|---|
| `1) Shop PromptPay number` | เบอร์พร้อมเพย์ของร้าน | เบอร์ 10 หลัก หรือเลขประจำตัว 13 หลัก ใช้สร้าง QR รับเงิน |
| `2) Starting password for all staff` | รหัสผ่านเริ่มต้นของพนักงาน | ตั้งใหม่อย่างน้อย 8 ตัว ทุกบัญชีใช้รหัสนี้ตอนเข้าครั้งแรก |
| `3) Printer share name` | ชื่อที่แชร์เครื่องพิมพ์ | กด Enter เฉย ๆ เพื่อใช้ `AmpornOMS-Receipt` |

ตรวจ: บรรทัดท้ายต้องขึ้นว่า `OK - 9 tables, 783 products, 4 user accounts` และ `INSTALL COMPLETE`

ค่าที่กรอกเก็บอยู่ในไฟล์ `.env` ในโฟลเดอร์เดียวกัน ถ้ากรอกผิด ให้ลบไฟล์ `.env` แล้วดับเบิลคลิก `install.bat` ใหม่ ข้อมูลร้านทั้งหมดอยู่ในโฟลเดอร์ `C:\AmpornOMS\data` ห้ามลบโฟลเดอร์นี้

## อัปเดตเป็นรุ่นใหม่ (ไม่ใช่ติดตั้งครั้งแรก)

**ห้ามรัน `install.bat`** และห้ามลบโฟลเดอร์เดิม เพราะข้อมูลการขายทั้งหมดอยู่ในโฟลเดอร์ `data` ของเครื่องนี้ ไม่ได้อยู่ในไฟล์ zip

1. ปิดหน้าต่าง `start.bat`
2. แตก `AmpornOMS.zip` ทับโฟลเดอร์เดิม (`C:\`) ถ้าถามให้กด Replace all
3. ดับเบิลคลิก `start.bat` ระบบปรับฐานข้อมูลเป็นรุ่นใหม่เอง ข้อมูลเดิมไม่หาย

ถ้าเผลอรัน `install.bat` แล้วขึ้น `WARNING ... ERASE ALL SALES DATA` ให้กด Enter เพื่อยกเลิก

## 2. เปิดระบบ

ดับเบิลคลิก **`start.bat`** ถ้า Windows ถามเรื่อง Firewall ให้กด Allow ทั้ง Private และ Public

ตรวจ: หน้าต่างขึ้นกรอบ `AMPORN OMS IS READY` และเบราว์เซอร์เปิดหน้าเข้าสู่ระบบให้เอง (ข้อความภาษาไทยในบรรทัด `[backend]` อาจเป็นสี่เหลี่ยม ไม่เป็นไร)

- **ใช้บนเครื่องนี้:** http://localhost:5173
- **ใช้บนมือถือ:** ต่อ Wi‑Fi ร้านวงเดียวกัน แล้วเปิดที่อยู่บรรทัด `Phone` ในกรอบ เช่น `http://192.168.1.20:5173`
- **ต้องเปิดหน้าต่างนี้ค้างไว้ตลอดที่ใช้งาน** ปิดหน้าต่างเท่ากับปิดระบบ วันต่อไปดับเบิลคลิก `start.bat` ใหม่

| ชื่อผู้ใช้ | บทบาท |
|---|---|
| `siriphan` `somporn` | พนักงานขาย |
| `santi` | พนักงานคลังสินค้า |
| `ning` | ผู้จัดการ |

ตรวจการทำงานครบหนึ่งรอบ:
1. เข้าเป็น `siriphan` ขายเหล็ก 2 หุนเต็ม (`101017`) หนึ่งเส้น กดแสดง QR แล้วกดยืนยันรับชำระเงิน ต้องได้เลขที่ ORD-…
2. เปิดอีกหน้าต่างแบบไม่ระบุตัวตน เข้าเป็น `santi` ต้องเห็นใบนั้นในคิว กดจ่ายสินค้าจนขึ้นส่งมอบสำเร็จ

## 3. ตั้งเครื่องพิมพ์ใบเสร็จ

1. ติดตั้งไดรเวอร์ TM-T82 จากเว็บ Epson ประเทศไทย (ค้นว่า "TM-T82 driver" เลือก Advanced Printer Driver)
2. ต่อสาย USB เปิดเครื่องพิมพ์ ใส่กระดาษ
3. เปิดการแชร์: Control Panel › Network and Sharing Center › Change advanced sharing settings › Turn on file and printer sharing
4. แชร์เครื่องพิมพ์: Settings › Printers & scanners › TM-T82 › Printer properties › แท็บ Sharing › ติ๊ก Share this printer › Share name ใส่ `AmpornOMS-Receipt` ให้ตัวพิมพ์ใหญ่เล็กตรงกัน › OK
5. ทดสอบ: เปิด Command Prompt แล้วรันทีละบรรทัด

```
cd %TEMP%
echo Amporn OMS test > test.txt
copy /b test.txt \\localhost\AmpornOMS-Receipt
```

ตรวจ: ต้องขึ้น `1 file(s) copied.` และกระดาษออกมามีคำว่า Amporn OMS test

ถ้าเปิดระบบค้างไว้ก่อนตั้งเครื่องพิมพ์ ให้ปิดหน้าต่าง `start.bat` แล้วเปิดใหม่

ถ้าเครื่องพิมพ์ต่อสาย LAN ไม่ต้องแชร์ ให้แก้บรรทัด `PRINTER_INTERFACE=tcp://IP-ของเครื่องพิมพ์:9100` ในไฟล์ `.env` แทน ดู IP จากใบทดสอบตัวเองของเครื่องพิมพ์

## 4. ทดสอบพิมพ์ใบเสร็จจริง (TC-12)

1. เข้าเป็น `siriphan` ขายสินค้าหนึ่งรายการ
2. กดยืนยันรับชำระเงินพร้อมกดจับเวลาในมือถือ หยุดเมื่อกระดาษขาดออกมา
3. ทำซ้ำอย่างน้อย 5 ครั้ง จดเวลาทุกครั้ง แล้วถ่ายรูปใบเสร็จให้เห็นภาษาไทยชัด ๆ

เกณฑ์ผ่าน: ภาษาไทยถูกต้อง คอลัมน์ตรง และเสร็จภายใน 5 วินาทีทุกครั้ง ถ้าไม่ผ่าน ให้จดอาการไว้ตามจริง

## 5. ปัญหาที่พบบ่อย

| อาการ | แก้ |
|---|---|
| หน้าต่างขึ้นแวบเดียวแล้วหาย | ยังไม่ได้แตก zip ดับเบิลคลิกจากในไฟล์ zip ตรง ๆ ให้ทำข้อ 1 ข้อย่อย 1 ก่อน |
| `สร้างฐานข้อมูลเริ่มต้นไม่สำเร็จ` หรือ `เปิดฐานข้อมูลไม่สำเร็จ` | เครื่องยังไม่มี Microsoft Visual C++ Redistributable ติดตั้งจาก https://aka.ms/vs/17/release/vc_redist.x64.exe แล้วลองใหม่ ถ้ายังไม่ได้ ส่งไฟล์ `data\mysql.log` ให้ผู้พัฒนา |
| `มีคำสั่งซื้ออยู่แล้ว … ข้อมูลการขายทั้งหมดจะหาย` | ระบบเคยใช้ขายจริงแล้ว ถ้าไม่ได้ตั้งใจล้างข้อมูล ให้กด Enter เพื่อยกเลิก |
| `EADDRINUSE` | มีหน้าต่าง `start.bat` หรือระบบรุ่นเก่าเปิดค้างอยู่ ปิดหน้าต่างเก่าก่อน |
| `Another AmpornOMS database is already running` หรือ `Access denied for user 'root'` | ฐานข้อมูลของสำเนาเก่าเปิดค้างอยู่ ปิดทุกหน้าต่างของ AmpornOMS แล้ว**รีสตาร์ทเครื่อง** · **ห้ามใช้ `taskkill /IM mysqld.exe`** เพราะจะปิดฐานข้อมูลของโปรแกรมอื่นในเครื่องด้วย เช่น Conmat5 |
| มือถือเข้าไม่ได้ | มือถือต้องต่อ Wi‑Fi วงเดียวกับ PC และต้องกด Allow ตอน Windows ถามเรื่อง Firewall |
| ใบเสร็จภาษาไทยเพี้ยน | เครื่องพิมพ์ใช้ตารางอักษรไทยคนละชุด พิมพ์ใบทดสอบตัวเอง (กดปุ่ม Feed ค้างขณะเปิดเครื่อง) ดูเลข code page ภาษาไทย แล้วแก้ `PRINTER_CODEPAGE` ใน `.env` |
| `copy` ขึ้น Access denied หรือ network path not found | ตรวจข้อ 3 ข้อย่อย 3 และ 4 อีกครั้ง |

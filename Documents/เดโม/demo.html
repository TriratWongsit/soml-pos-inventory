เรื่อง UAT (พูดตามนี้)

UAT ยังไม่ได้ทดสอบ เพราะต้องให้พนักงานจริงใช้งานต่อเนื่อง 1 สัปดาห์ตาม scenario ในสไลด์ ขออนุญาตกรรมการขอเวลาเพื่อทำ UAT ครับ

เตรียมก่อนเข้าห้อง

  1. cd soml แล้ว npm run db:reset เพื่อเริ่มจากข้อมูลสะอาด แล้ว npm run dev
  2. ผู้จัดการตั้งสินค้าตัวหนึ่งให้เหลือ 1 ชิ้น (ใช้ D-6) และอีกตัวสต็อก 12 จุดสั่งซื้อเพิ่ม 10 (ใช้ D-7)
  3. มือถือต่อ Wi-Fi วงเดียวกับคอม เปิด http://<IP เครื่อง>:5173 เข้าบัญชีพนักงานคลัง แผนสำรอง: hotspot มือถือ หรือเปิดสองหน้าต่างบนคอม
  4. คอมเปิดสองหน้าต่าง หน้าต่างปกติเป็นพนักงานขาย หน้าต่างไม่ระบุตัวตนเป็นผู้จัดการ
  5. VS Code เปิดโฟลเดอร์ soml ไว้ กด Cmd+P พิมพ์ ไฟล์:บรรทัด หรือ Cmd+Shift+F ค้น [D-4] เพื่อไปที่จุดของข้อนั้น
  6. System test อัตโนมัติสร้างข้อมูลจริงลงฐาน ให้รันหลังเดโมด้วยมือ และลองโหมด --headed ล่วงหน้าหนึ่งรอบ

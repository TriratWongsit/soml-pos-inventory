เดโมไกด์ วันสอบ · อำพร OMS

ใช้คู่กับ "ใบลำดับเดโม System Test" (มีเลขบรรทัดโค้ด) ไกด์นี้บอกวิธีตั้งเครื่อง เตรียมข้อมูล ลำดับการกด สิ่งที่ต้องพูด และแผนสำรอง เวลาเดโมประมาณ 10–12 นาที

1. จัดเครื่อง

เครื่องหน้าที่เปิดอะไร
Windows (ต่อเครื่องพิมพ์ TM-T82)เครื่องร้าน: รันระบบ + หน้าขาย + ผู้จัดการstart.bat · Chrome ธรรมดา = พนักงานขาย · Chrome ไม่ระบุตัวตน (Ctrl+Shift+N) = ผู้จัดการ
Macจอคลัง + เปิดโค้ด + รันเทสChrome ที่ http://<IP Windows>:5173 = พนักงานคลัง · VS Code โฟลเดอร์ soml
มือถือ (ถ้ามี)จอคลังแทน Mac ให้เห็นว่าใช้ในโกดังได้เบราว์เซอร์ที่ http://<IP Windows>:5173
ทุกเครื่องต้องอยู่ Wi-Fi หรือ Hotspot วงเดียวกัน ใช้ Hotspot มือถือชัวร์ที่สุด เพราะ Wi-Fi มหาวิทยาลัยบางวงไม่ให้เครื่องคุยกันเอง IP ของ Windows ดูได้จากหน้าต่าง start.bat บรรทัด "มือถือ : http://..."
บัญชี: พนักงานขาย siriphan · พนักงานคลัง santi · ผู้จัดการ ning · รหัสผ่านคือที่ตั้งตอน install.bat (ไม่เขียนไว้ในเอกสารนี้)

2. เตรียมก่อนวันสอบ (ทำที่บ้าน)

  1. Windows: แตก AmpornOMS.zip ชุดล่าสุดทับ C:\AmpornOMS แล้วเปิด start.bat
  2. ทดสอบเครื่องพิมพ์: Command Prompt พิมพ์ copy /b test.txt \\localhost\AmpornOMS-Receipt ต้องมีกระดาษออก
  3. ทดสอบจอคลัง: Mac เปิด http://<IP Windows>:5173 ได้ ถ้าไม่ได้ ตอน Windows ถามเรื่อง Firewall ต้องกด Allow
  4. ซ้อมเดโมครบ 8 ข้อ อย่างน้อย 2 รอบ จับเวลา
  5. Mac: node start.js แล้วรัน npx playwright test --headed tests/system/acceptance.spec.js ต้องผ่าน 13 ข้อ
  6. ชาร์จแบต ทุกเครื่อง พกสาย USB เครื่องพิมพ์ กระดาษสำรอง และปลั๊กพ่วง

3. เช้าวันสอบ (ก่อนเข้าห้อง 15 นาที)

  1. ล้างข้อมูลให้สะอาด (เฉพาะเครื่องที่ใช้เดโม): ดับเบิลคลิก install.bat แล้วพิมพ์ ลบ เพื่อยืนยัน จะได้สินค้า 783 รายการ ผู้ใช้ 4 บัญชี คิวว่าง
  2. เปิด start.bat จดเลข IP ในบรรทัด "มือถือ"
  3. ตั้งสินค้าสองตัว (เข้าเป็นผู้จัดการ หน้าสินค้า) แล้วจดชื่อไว้
    • สินค้า A (ใช้ D-6): ปรับสต็อกให้เหลือ 1
    • สินค้า B (ใช้ D-7): สต็อก 12 จุดสั่งซื้อเพิ่ม 10
  4. เปิดหน้าต่างตามข้อ 1 เข้าบัญชีให้ครบ Mac เปิดหน้าคิวค้างไว้
  5. VS Code บน Mac เปิดไฟล์ stock-deduction/index.js รอไว้ (ไฟล์ที่อาจารย์น่าจะขอดูที่สุด)
ห้ามล้างข้อมูลบนเครื่องร้านจริงที่ขายของจริงอยู่ install.bat จะลบการขายทั้งหมด ถ้า Windows เป็นเครื่องร้านจริง ให้ข้ามข้อ 1 และใช้สินค้าที่เตรียมไว้แทน

4. ลำดับเดโม (เล่าเป็นเรื่องเดียว ลูกค้ามาซื้อ → ผู้จัดการดูยอด)

5. ถ้าอาจารย์ขอดูโค้ดหรือขอให้รันเทส (ใช้ Mac)

  • เปิดโค้ด: VS Code กด Cmd+Shift+F พิมพ์ [D-5] (เลขตามข้อที่ถาม) จะเห็นทุกบรรทัดของข้อนั้น หรือ Cmd+P พิมพ์ ไฟล์:บรรทัด จากใบลำดับเดโม
  • เทสหลังบ้านทั้งหมด: npm test → 134 passed
  • เทสกันจ่ายซ้ำข้อเดียว: npx jest backend/tests/integration/dispatch.test.js
  • System test เห็นเบราว์เซอร์: npx playwright test --headed tests/system/acceptance.spec.js:132 (ต้องเปิด node start.js บน Mac ก่อน)
  • เดินทีละขั้น: npx playwright test --debug tests/system/acceptance.spec.js:132

6. ถ้ามีปัญหาระหว่างเดโม

อาการทำทันที
ใบเสร็จไม่ออกดูหน้าต่าง start.bat บรรทัด [print] · ถ้า "network name cannot be found" แชร์เครื่องพิมพ์ชื่อ AmpornOMS-Receipt ใหม่ · พูดว่า "การขายยังสำเร็จแม้พิมพ์ไม่ได้ ตามที่ออกแบบให้บริการพิมพ์แยก" แล้วเปิดรูปใบเสร็จจริงรูปที่ 4.13 ในเล่ม
Mac เข้าหน้าคิวไม่ได้เช็ค Wi-Fi วงเดียวกัน · ใช้ IP จาก start.bat · แผนสำรอง: เปิดหน้าคิวบน Windows อีกหน้าต่าง (ไม่ระบุตัวตนอีกบัญชี หรือ Edge) วางคู่กัน
คิวไม่อัปเดตเองรอ 3 วินาที (อาจถอยไปใช้ SSE) · ถ้ายังไม่ขึ้นค่อยรีเฟรชหนึ่งครั้ง แล้วอธิบายตามจริง
start.bat ขึ้น EADDRINUSEมีหน้าต่างระบบเก่าเปิดค้าง ปิดทุกหน้าต่างแล้วเปิดใหม่
Mac รันเทสแล้วต่อ MySQL ไม่ได้ (mysql.sock)brew services restart mysql@8.0
Mac รันเทสแล้ว Failed running server.jsมีระบบเปิดซ้ำ ปิดทุกแท็บด้วย Ctrl+C แล้วเปิด node start.js ตัวเดียว

7. คำถามที่ต้องตอบได้ระหว่างเดโม

  • ใครทำส่วนไหน: ตรัยรัตน์ หลังบ้าน BE-01–10 ฐานข้อมูล บริการพิมพ์ เทสหลังบ้าน · พนาวุฒน์ หน้าจอ FE-01–09 และมือถือ (อาจารย์ประเมินรายคน)
  • UAT: ยังไม่ได้ทำ ต้องใช้จริง 1 สัปดาห์ตาม scenario ขออนุญาตกรรมการขอเวลาทำ UAT
  • ทำไมไม่เชื่อมธนาคาร: อยู่นอกขอบเขต พนักงานดูแอปธนาคารแล้วยืนยันเอง เสนอเป็นงานต่อยอด
  • เครื่องดับข้อมูลหายไหม: ไม่หาย บันทึกลงดิสก์แล้ว แต่ถ้าฮาร์ดดิสก์เสียจะหาย เพราะยังไม่มี backup (ข้อจำกัด 5.3.7)

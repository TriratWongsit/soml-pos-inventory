สคริปต์เดโมแอปตาม Use Case

ระบบจัดการคำสั่งซื้อและตรวจสอบคลังสินค้า ร้านวัสดุก่อสร้างอำพรคอนกรีต (SOML)

เฉพาะส่วนเดโมแอป · เน้นตอบสิ่งที่อาจารย์ขอ · ความยาวเป้าหมายประมาณ 20 นาที

สิ่งที่อาจารย์ขอ และเดโมนี้ตอบอย่างไร

| อาจารย์ขอ | ในวิดีโอจะให้เห็นแบบนี้ |
|---|---|
| มีกี่ use case แต่ละอันครอบคลุม requirement ข้อไหน | ทุก UC เริ่มด้วยการพูดว่า "UC นี้รองรับ FR ข้อ…" และท้ายวิดีโอเปิดตารางสรุปทั้ง 11 กรณี |
| ทุก use case มี step โปรแกรมต้องทำงานตามนั้น | ทำในแอปทีละขั้นตามขั้นตอนของ UC แล้วพูดว่ากำลังทำขั้นที่เท่าไร |
| ทุก use case มี acceptance criteria เป็นเงื่อนไขยอมรับ | ทุก UC บอกว่า AC คืออะไร แล้วชี้ให้เห็นบนจอว่าผ่านเงื่อนไขนั้น |
| ทุก use case มี UI | บอกชื่อหน้าจอและเส้นทางที่ใช้ |
| มี data ที่ใช้ ซึ่งนำไปสู่ ERD | หลังทำแต่ละ UC เปิดฐานข้อมูลให้เห็นแถวที่เพิ่งเกิดหรือเปลี่ยน แล้วบอกว่าเป็นตารางไหนใน ERD และเชื่อมกับตารางไหน |
| มองออกไหมว่าอะไรสัมพันธ์กับอะไร | ปิดท้ายด้วยการเล่าหนึ่งสายตั้งแต่ปัญหาจนถึงแถวในฐานข้อมูล |

วิธีใช้สคริปต์: อ่านช่อง "พูด" ให้เข้าใจ แล้วพูดด้วยคำของตัวเอง ไม่ต้องอ่านตาม ถ้าพูดผิดก็พูดแก้ต่อได้เลย

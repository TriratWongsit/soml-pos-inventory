กรณีทดสอบแบบเหตุการณ์ · อำพร OMS

ใช้ทดสอบด้วยตัวเองก่อนสอบ แต่ละกรณีบอกเหตุการณ์ ขั้นตอน ผลที่คาดหวัง และเส้นทางในโค้ดว่ามาจากโมดูลไหน เรียกจากไหน · อ้างอิงกรณีทดสอบ TC-01 ถึง TC-13 ตารางที่ 3.29 และเกณฑ์ AC ตารางที่ 3.11

ก่อนเริ่ม

  1. เปิดระบบ: cd soml แล้ว npm run dev หน้าจออยู่ที่ http://localhost:5173 หลังบ้าน :4000 บริการพิมพ์ :4100
  2. อยากเริ่มจากข้อมูลสะอาด: npm run db:reset (ล้างฐานใช้งานกลับเป็นสินค้า 783 รายการและผู้ใช้ตั้งต้น)
  3. ชื่อผู้ใช้ทั้งสามบทบาทอยู่ใน db/seed/seed-users.js
  4. มือถือใช้ http://<IP เครื่อง>:5173 ใน Wi-Fi เดียวกัน
